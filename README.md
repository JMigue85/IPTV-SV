## 🚀 Reproductores Recomendados

### 📱 Android (Recomendación principal)
**Televizo** + **MPV** como reproductor externo *(la mejor combinación probada)*

### 💻 PC
- **FredTV** (mejor opción)
- **MPV Player**
- **IPTVnator**

### 🍏 macOS
**IPTVnator** *(Alternativa recomendada)*

### 📱 iPhone / iPad
**GSE Smart IPTV** + **VLC** como reproductor externo *(Alternativa recomendada)*

### 📺 Smart TV
- *Android TV:* **Televizo**
- *Samsung, LG y otras:* **IPTV Smarters Pro** (Carga manual del archivo `.m3u`)

> 💡 **Tip importante para canales no fluidos o pantalla negra:** Se recomienda encarecidamente usar un reproductor externo (MPV como primera opción, o VLC como alternativa).

### ⚙️ Ajustes recomendados:
*   Activa la **Decodificación por Software** en los ajustes de MPV y VLC para una mayor compatibilidad de video.
