## 🚀 Reproductores Recomendados

*   **Android (Recomendación principal):** **Televizo** + **MPV** como reproductor externo *(la mejor combinación probada)*.
*   **PC:** **FredTV** (mejor opción), **MPV Player** o **IPTVnator**.
*   **macOS:** **IPTVnator** *(Alternativa recomendada - No probada personalmente)*.
*   **iPhone / iPad:** **GSE Smart IPTV** + **VLC** como reproductor externo *(Alternativa recomendada - No probada personalmente)*.
*   **Smart TV:** 
    *   *Android TV:* **Televizo**.
    *   *Samsung, LG y otras:* **IPTV Smarters Pro** *(Requiere cargar el archivo `IPTVSV.m3u` descargado - Actualización manual)*.

> 💡 **Tip importante para canales TCS (2, 4, 6 y SV+):** Se recomienda encarecidamente usar un reproductor externo (MPV como primera opción, o VLC como alternativa).

### ⚙️ Ajustes recomendados:
*   Activa la **Decodificación por Software** en los ajustes de MPV y VLC para una mayor compatibilidad de video.
